# Scalp Studio · 纹发三维预览

浏览器内运行的纹发设计原型，支持五角度照片投影贴图、可调参数头模、发际线与覆盖区域、色素密度与颜色，以及前后对比 PNG 导出。

## 使用

打开 GitHub Pages 网站，或下载 `index.html` 后用浏览器打开。按拍摄指引上传正面、左右侧面、头顶和后脑照片，校准贴图位置与头型，然后调整纹发方案。拖动旋转、滚轮缩放，导出对比图或保存方案 JSON。

## 当前范围

- 采用参数头模与照片投影贴图，**不执行摄影测量，也不自动重建客户真实三维头型**。
- 被头发遮挡的头皮无法从这些照片恢复；模型下部不是精确面部重建。
- 预览仅供设计沟通，不保证实际纹发效果。颜色与密度滑块不对应施术剂量。
- 照片仅保留在页面内存，不上传服务器；刷新或清空即移除。
- 方案 JSON 不包含照片。

## 实现与验证

自包含 HTML、CSS 与 JavaScript Canvas 软件三维渲染，无外部运行依赖。已完成脚本启动、绘制计算、视角、覆盖预设、零密度及照片投影计算检查。
